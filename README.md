# web3-wallet-connect-

نمایشگر واریزی‌های کیف‌پول TRON (USDT TRC-20) با اعلان تلگرام. فقط به کیف‌پول شما وصل است؛ به هیچ سایت فروشگاهی وصل نیست و هیچ کلید خصوصی یا امضایی لازم ندارد (فقط خواندن اطلاعات عمومی بلاک‌چین).

- `monitor.py` + GitHub Actions: هر چند دقیقه واریزهای جدید USDT به کیف‌پول را بررسی و در تلگرام اعلام می‌کند (مبلغ، فرستنده، موجودی، لینک Tronscan).
- `index.html` (GitHub Pages): داشبورد فقط‌خواندنی موجودی و آخرین واریزها.

## تنظیمات
Settings → Secrets and variables → Actions:
- Secret `TELEGRAM_TOKEN`: توکن ربات
- Secret `CHAT_ID`: شناسه چت (نام `CHT_ID` هم کار می‌کند)
- اختیاری: Variable `WALLET_ADDRESS` برای تغییر کیف‌پول، Secret `TRONGRID_API_KEY`

اجرای اول یک پیام «نمایشگر فعال شد» به تلگرام می‌فرستد؛ اگر نرسید، توکن یا شناسه چت را بررسی کنید.
نکته: GitHub زمان‌بندی‌ها را گاهی با تأخیر اجرا می‌کند، پس اعلان ممکن است چند دقیقه دیرتر برسد.
